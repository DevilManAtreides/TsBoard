# TsBoard

A terminal-aware, fully customizable Android keyboard.

- Key styles, key light (RGB), press animations, custom sounds and backgrounds
- App profiles: a different look, layout and settings for each app
- Export / import your whole look

TsBoard is free software under the GNU General Public License v3.0 (see `LICENSE`) and is built on the open source keyboard HeliBoard, which is based on the Android Open Source Project keyboard.
